# ⚽ KnowPitch 球知 - 用足球阵型学知识

Put your knowledge on the pitch.

## 这是什么

KnowPitch（球知）是一个 AI Agent Skill，把任何知识领域拆解成"一支足球队"来深入学习与讲透。

- **主教练** = 一句话核心思想
- **门将** = 最底层基础/第一性原理
- **后卫** = 基础概念
- **中场** = 机制/方法/思想
- **前锋** = 应用/结论
- **替补席** = 进阶知识点

## 输出产物

1. **阵型图 SVG** - 可视化知识结构
2. **球员卡** - ELI5 风格大白话讲解
3. **战术板** - 学习路径与知识连线

## 支持的阵型

4-3-3、4-2-3-1、4-3-2-1、4-4-2、4-5-1、4-1-4-1、3-5-2、3-4-3

## 触发方式

在支持 Skill 的 AI Agent 中输入：
- `kp11 通货膨胀`
- `kpt 机器学习`
- `kpitch React Hooks`
- `knowpitch 区块链`
