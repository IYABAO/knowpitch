## 示例 1：机器学习（kp11，4-2-3-1 + B 队）

**用户输入：** `kp11 讲一下机器学习`

**主教练：** 机器学习 = 让电脑从数据中自己找规律，而不是人写死规则

**首发阵容（4-2-3-1）：**

**门将 GK｜什么是 "从数据找规律"**

- 是什么：电脑看很多例子，自己总结出规律，不用人一条条写规则
- 像什么：小孩看了很多猫的照片，自己学会认猫，没人教他 "猫有四条腿 + 尾巴 + 耳朵"
- 传给谁：所有球员都基于这个基础
- 为什么在这：这是机器学习的定义，丢了就全崩

**后卫 CB｜特征 / 标签 / 训练集**

- 是什么：特征是输入的数据，标签是答案，训练集是学习用的题库
- 像什么：练习题（特征）+ 答案（标签）+ 一本题库（训练集）
- 传给谁：给 CDM（梯度下降）提供原料
- 为什么在这：没有数据就没法学习，这是地基

**后腰 CDM｜梯度下降**

- 是什么：一步步调整参数，让预测错误越来越小的优化方法
- 像什么：蒙眼下山，每步都往最陡的方向走，直到走到谷底
- 传给谁：给 CM（损失函数）提供优化方向
- 为什么在这：这是机器学习的核心机制，所有模型都靠它训练

**后腰 CDM｜损失函数**

- 是什么：衡量预测有多错的函数，错得越多分越高
- 像什么：考试扣分，错一题扣一分，目标是扣到 0 分
- 传给谁：和梯度下降强相关，告诉它 "往哪走能减少错误"
- 为什么在这：没有损失函数就不知道 "学对了没有"

**前腰 AMD｜监督学习**

- 是什么：给电脑看 "题目 + 答案"，让它学会从题目推答案
- 像什么：做练习题对答案，做多了就会考试了
- 传给谁：给 LW（分类 / 回归）提供理论基础
- 为什么在这：这是最常用的机器学习范式

**前腰 AMD｜无监督学习**

- 是什么：只给电脑看 "题目" 不给答案，让它自己找规律
- 像什么：给你一堆水果，不告诉你分类，你自己按颜色 / 形状分组
- 传给谁：给 RW（聚类 / 降维）提供理论基础
- 为什么在这：这是发现隐藏模式的核心思想

**前腰 AMD｜强化学习**

- 是什么：电脑通过 "试错 + 奖励" 学习，做对加分做错扣分
- 像什么：训练小狗，做对给零食，做错轻轻拍一下
- 传给谁：给 CF（预测）提供另一条路径
- 为什么在这：这是决策类问题的核心思想

**边锋 LW｜分类与回归**

- 是什么：分类是预测类别（猫 / 狗），回归是预测数值（房价）
- 像什么：分类是选择题，回归是填空题
- 传给谁：给 CF（预测）提供具体应用方法
- 为什么在这：这是监督学习最常见的应用场景

**边锋 RW｜聚类与降维**

- 是什么：聚类是自动分组，降维是把高维数据变简单
- 像什么：聚类是整理衣柜（按季节分），降维是把厚书浓缩成思维导图
- 传给谁：给 CF（预测）提供无监督应用
- 为什么在这：这是无监督学习的主要应用

**中锋 CF｜预测**

- 是什么：用训练好的模型对新数据做出判断
- 像什么：学会了知识点后去考试，对没见过的题作答
- 传给谁：最终输出，全队服务的目标
- 为什么在这：这是机器学习的最终目的 —— 预测

**替补席：**

- 过拟合 / 欠拟合（进阶概念）
- 正则化（防止过拟合的方法）
- 交叉验证（评估模型的方法）
- 特征工程（数据预处理）

**阵型图：** [SVG]

**教练战术板：**

- 为什么用 4-2-3-1：机器学习有一个明确的最终目标（预测），双后腰（梯度下降 + 损失函数）是核心机制，三前腰（三大范式）给目标喂球
- 球路（学习路径）：GK → CB → CDM → AMD → CF
- 关键连线：梯度下降 ↔ 损失函数（互相依赖）；监督学习 ↔ 分类 / 回归（理论→应用）
- 三种输球方式：
  1. 过拟合：模型死记硬背训练数据，换新题就不会（像背答案不理解）
  2. 欠拟合：模型太简单，连训练数据都学不会（像基础太差）
  3. 数据泄露：测试数据混进训练集，成绩虚高（像考试前偷看了答案）

**B 队（3-4-3，进阶应用）：**

- B 队教练：机器学习在真实世界的应用
- 前锋：计算机视觉（CV）、自然语言处理（NLP）、推荐系统
- 中场：深度学习、集成学习、迁移学习、在线学习
- 后卫：卷积神经网络（CNN）、循环神经网络（RNN）、Transformer

## 示例 2：通货膨胀（kpt，4-3-3 精简）

**用户输入：** `kpt 讲一下通货膨胀`

**主教练：** 通货膨胀 = 钱变多了，但东西没多，所以钱不值钱了

**首发阵容（4-3-3，精简 6 人）：**

**门将 GK｜货币与价格**

- 是什么：钱是交换的媒介，价格是东西值多少钱
- 像什么：钱是票，东西是演出，票印多了每张就不值钱了
- 传给谁：所有球员的基础
- 为什么在这：不懂货币就不懂通胀

**后卫 CB｜需求拉动**

- 是什么：大家都想买，东西不够，价格就涨了
- 像什么：演唱会门票，抢的人多了黄牛就加价
- 传给谁：给 CM（货币政策）提供原因
- 为什么在这：这是通胀的主要原因之一

**后腰 CDM｜货币乘数**

- 是什么：银行把钱贷出去，钱就变多了（100 块存款能变出 500 块贷款）
- 像什么：魔术师的帽子，放进去 1 只兔子，能变出 5 只
- 传给谁：给 CM（货币政策）提供机制
- 为什么在这：这是钱变多的核心机制

**中前卫 CM｜货币政策工具**

- 是什么：央行通过加息 / 降息、印钱 / 收钱来控制货币量
- 像什么：水龙头，拧大水流大（通胀），拧小水流小（通缩）
- 传给谁：给 CF（钱包影响）提供手段
- 为什么在这：这是控制通胀的方法

**边锋 LW｜历史案例**

- 是什么：德国 1923 年（买面包要推车钱）、津巴布韦（万亿面值钞票）
- 像什么：极端的反面教材，告诉你失控有多可怕
- 传给谁：给 CF（钱包影响）提供实证
- 为什么在这：案例让抽象概念变具体

**中锋 CF｜通胀怎么影响你的钱包**

- 是什么：工资不涨但物价涨，实际购买力下降
- 像什么：你口袋里的钱没变，但能买的东西变少了
- 传给谁：最终结论
- 为什么在这：这是大家最关心的 —— 通胀和我有什么关系

**阵型图：** [SVG]

**教练战术板：**

- 为什么用 4-3-3：通胀是均衡主题，原因（需求）、机制（货币乘数）、影响（钱包）三层都有
- 球路：GK → CB → CDM → CM → CF
- 关键连线：货币乘数 ↔ 货币政策（机制和手段互相影响）
- 三种输球方式：
  1. 把通胀当成 "物价上涨"（通胀是货币现象，不是所有涨价都是通胀）
  2. 以为加息立刻能降通胀（货币政策有 6-18 个月滞后）
  3. 以为工资涨能跑赢通胀（工资通常涨得比物价慢）

## 示例 3：数据库索引（kp11 --age 5，给 5 岁小孩讲）

**用户输入：** `kp11 数据库索引 --age 5`

**主教练：** 索引 = 书的目录，找东西不用一页页翻

**首发阵容（4-3-3，精简 5 人，5 岁语言）：**

**门将 GK｜什么是索引**

- 是什么：就像书前面的目录
- 像什么：你想看恐龙那页，看目录就知道在第 50 页，不用从第 1 页翻
- 传给谁：所有人的基础
- 为什么在这：不懂目录就不懂索引

**后卫 CB｜没有索引会怎样**

- 是什么：要一页一页翻，很慢很慢
- 像什么：1000 页的书，找 "小红帽" 要翻 500 页
- 传给谁：给 CDM（为什么快）提供对比
- 为什么在这：知道 "慢" 才懂 "快" 的好

**后腰 CDM｜为什么索引快**

- 是什么：目录告诉你在哪一页，直接翻过去
- 像什么：玩躲猫猫，有人告诉你 "他在柜子里"，你不用到处找
- 传给谁：给 CF（结果）提供原因
- 为什么在这：这是索引的核心魔法

**边锋 LW｜生活中的索引**

- 是什么：字典的拼音检字表、超市的分类牌
- 像什么：超市写着 "零食区"，你直接走过去，不用每个货架都看
- 传给谁：给 CF（结果）提供例子
- 为什么在这：例子让抽象变具体

**中锋 CF｜结果**

- 是什么：找东西又快又准
- 像什么：有了目录，1 秒钟找到，不用翻 10 分钟
- 传给谁：最终答案
- 为什么在这：这是索引的目的 —— 快

**阵型图：** [SVG]

**教练战术板：**

- 为什么用 4-3-3：均衡主题，是什么→为什么→例子→结果
- 球路：GK → CB → CDM → CF
- 关键连线：没有索引（慢）↔ 有索引（快）（对比关系）
- 三种输球方式：
  1. 以为索引是 "另一份数据"（索引是目录，不是内容）
  2. 以为所有东西都要索引（太多目录反而慢）
  3. 以为索引永远不会变（书加了新内容，目录也要更新）
