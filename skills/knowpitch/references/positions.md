# 位置与知识角色映射表

每个知识点在阵型中的位置，由它在知识体系里的"职能"决定——不是按重要性排序，
而是按"它在整支球队里干什么活"。

## 一句话原则

> 门将守底线，后卫打地基，中场转起来，前锋去进球。
> 教练（主教练）不进球，但他决定所有人怎么踢。

## 角色 → 位置 对照表

| 队内角色 | 位置代码 | 中文位置 | 在知识体系里干什么 | 适合放什么知识点 |
|---|---|---|---|---|
| 主教练 | HC | 主教练 | 全队灵魂：用一句话给出统领全局的核心思想 / 中心比喻。所有知识点都围绕它运转 | 主题的核心洞察（"整件事说白了就是……"） |
| 门将 | GK | 门将 | 底线：最后一道防线。这块丢了全盘皆输——最底层、最不可妥协的基础 | 定义、公理、第一性原理、"XX 到底是什么" |
| 中后卫 | CB | 中后卫 | 骨架：支撑全局的核心基础概念，别人都从它身上长出来 | 主干概念、核心定义、基本对象 |
| 边后卫 | LB / RB | 左/右后卫 | 两翼支柱：给骨架提供支撑的背景与前置知识 | 背景、历史、前置条件、分类学、相邻学科 |
| 后腰 | CDM | 后腰 | 引擎室：系统底层怎么运转的机制与原理 | 机制、原理、"底层是怎么工作的" |
| 中前卫 | CM | 中前卫 | 运转枢纽：把机制变成可执行的关键过程与方法 | 方法、流程、步骤、算法、操作流程 |
| 前腰 | AMD（=CAM） | 前腰 | 大脑：创造机会的核心思想、关键理论、策略性概念 | 核心理论、关键思想、策略、模型 |
| 边锋 | LW / RW | 左/右边锋 | 两翼攻击：把理论落到现实的主要应用场景与案例 | 应用、案例、落地、实战例子 |
| 中锋 | CF | 中锋 | 终结点：这门知识最终要回答的核心结论 / 主要产出 | 核心结论、主要答案、"所以最终是……" |
| 影锋 | SS | 影锋 | 二前锋：站在核心结论旁边的衍生结论与重要推论 | 衍生结论、推论、次要产出、权衡 |
| 替补 | SUB | 替补席 | 备用：进阶、冷门、边角、非主流但相关的知识点 | 进阶内容、边角料、争议点、"想再多学一点" |
| B 队 | 任意 | B 队 | 第二阵容：主力放不下的扩展知识点（>20 个主流知识点时启用） | 进阶扩展区，配 B 队教练（次级核心思想） |

## 排位时的高频决策

- **拿不准放哪**：先问"这个知识点掉进 5 个桶里的哪个——地基(守)、机制(转)、思想(想)、应用(打)、结论(进)"。
- **同时像机制又像方法**：偏"为什么能转"→ CDM；偏"怎么做"→ CM。
- **同时像应用又像结论**：案例/例子 → LW/RW；最终答案 → CF；跟在结论后的推论 → SS。
- **基础太薄**：把最底层的东西放 GK，第二层放 CB，背景放 LB/RB，宁缺毋滥，空位就是"你可以继续深挖的位置"。
- **别把 11 人硬凑满**：知识点不够 11 个时，留空位并明确写出"这几个位置还可以继续学什么"，比硬塞凑数好。
